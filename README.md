# Restaurant FLK

Aplicación Android para restaurantes desarrollada con **Kotlin**, **Jetpack Compose**, **MVVM**, **Koin** y preparada para **Firebase**.

## Incluye

- Jetpack Compose + Material 3
- Arquitectura MVVM
- Inyección de dependencias con Koin
- Navegación por rutas
- Dependencias configuradas
- Recursos e imágenes incluidos

## Inicio rápido

1. Abrir en Android Studio.
2. Añadir `google-services.json` en `app/`.
3. Sincronizar Gradle y ejecutar.

**Stack:** Kotlin · Jetpack Compose · MVVM · Koin · Firebase
